P0 — Concept freeze · done

Lock Option A: two-wing motor + linkage + elastic return + passive pitch. Hover-capable education/research, short endurance, indoor first.

Exit: this viewer matches the locked archetype (two wings, span freeze, nature→tech rows).

P1 — Bench

Build the drivetrain and elastic on a block. Sweep frequency. Watch backlash, film, and the flexure.

Exit: the mechanism survives a flap session without coming apart.

P2 — Tethered flap

Umbilical power. Same airframe, now on a stand. Look for a lift trace and a current waveform that is boring.

Exit: tethered hover without breaking.

P3 — Free flight (indoor)

1S pack on board only after P2 is dull. IMU rate damping. Soft room, spotter.

Exit: a short indoor hop that was intended, then a landing or a cheap crash.

P4 — Demo

Repeatable indoor hover for teaching the elastic + LEV story. Endurance stays short on purpose.

Exit: someone else can run the demo from a checklist.
