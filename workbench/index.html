Overview

Living catalog, not a “frozen forever” banner. Locks below are the ones Corey already stamped — this page does not invent new ones.

Vision

A mobile kit of latching tiles that rolls up to a semi-permanent X1. X1 stays the cut station. Workbench tiles make giant flats, infeed/outfeed, and the first tool-top (miter). Every module shares one 36×36″ face so any side docks any side.

Distinct program from the X1 stand (wood + orange) and from Flyer-0 (magenta). Amber is the workbench accent on purpose.

First trio

Flat — plain top, lower shelf, optional drawer bay, full 4-side latch. Default island tile. This is the primary 3D.

Extension — same OA and latch, lighter utility (slatted shelf, fewer braces). Docks to Flat or Miter to grow giant flats or infeed/outfeed.

Miter — same frame; top is a recess envelope for a DeWalt DWS716XPS (12″ double-bevel compound, not a slider). Saw mesh here is a schematic box. Corey swing-tape still open.
