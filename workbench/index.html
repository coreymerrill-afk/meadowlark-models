Workbench Gen-0

Modular 36×36″ tiles · 38″ AFF · first trio Flat / Extension / Miter (DWS716XPS)

Vision

A mobile kit of latching tiles that rolls up to a semi-permanent X1. X1 stays the cut station. Workbench tiles make giant flats, infeed/outfeed, and the first tool-top. Every module shares one 36×36″ face so any side docks any side.

Amber is the workbench accent on purpose — distinct from the X1 stand and from Flyer-0 magenta. This page is so Corey can confirm the program is real.
