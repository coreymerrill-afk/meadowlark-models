Workbench Gen-0

Rolling 36×36 inch tables · 38 inches tall · Flat / Extension / Miter (DWS716XPS)

What this is

A set of rolling shop tables that park around the X1 stand. The X1 stays put and does the cutting. These tables roll in, snap together with magnets, then latch, and make a bigger work surface — or hold the first saw.

Three pieces in this first set: Flat (plain table), Extension (lighter helper), and Miter (DWS716XPS) (the DeWalt saw station). Every table is the same 36×36 inch outer size, so any side can join any side.

This page is a draft so you can see the program is real. Amber on purpose — not the X1 stand, not the insect flyer.

How they joinMagnets snap them together, then two latches per side take the load. The first latch sits 12 inches below the top (about 26 inches off the floor) — not 18. The second sits on the same line, typically 6–8 inches above or below (exact offset still a draft).
Plywood½ inch for plates the X1 can cut. ¾ inch for tops and shelves that hold weight.
